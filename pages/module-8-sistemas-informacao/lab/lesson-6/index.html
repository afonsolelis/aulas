Dimensional modelling in the browser

DuckDB runs inside this page. Every date is Unix time, in seconds. The table db_ingestion holds what was captured from TCGplayer about the Pokémon TCG sets of 2026 and is kept in the localStorage of the browser, together with every statement that created an object, so the model survives a reload. Each step has a CREATE prompt for the coding agent and the reference SQL of the professor.

Drill-down explorer

The chart reads the materialized report of September or the live report, and groups it by the dimensions checked below. Checking a dimension drills down, unchecking it rolls up, and clicking a bar descends into that member along set › rarity › card. Every view is one cell level of the cube; the side panel shows the SQL and the matching cells of gold.agg_price_cube.
