Pricing the DataApp on AWS

Every line of a cloud bill is a quantity of the workload multiplied by a unit price. The workload is the run of tcg-dataapp measured on 08/11/2026, and the unit prices are a snapshot of the public AWS Price List taken on the same day, each one with the offer and the usage type it came from. The calculator below prices five architectures for that workload; every quantity and every price can be edited, and the changes stay in this browser.

The same workload in two regions and at three frequencies

Both tables use every setting of the calculator except the one they vary: the first changes only the region, the second only the number of runs per month.

Virginia against São Paulo

The ratio is the São Paulo total divided by the Virginia total. Data residency or the latency of the readers can still require São Paulo; the ratio is the price of that requirement.

Runs per month

An instance always on costs the same at any frequency; a service billed per use grows with the runs. The ranking of the architectures depends on the workload, not on the services alone.

Unit prices of the region

Snapshot of the AWS Price List consulted on 08/11/2026, through the public Bulk API that needs no account. Each price shows its offer, its usage type and the date on which AWS published that offer. A value typed here replaces the snapshot in this browser only, and the field turns purple until it is reset.
