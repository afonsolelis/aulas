2. Why a DataApp must be observed

The package of Lesson 7 records every attempt of every task in ops.pipeline_runs, which explains a run once someone decides to look at it. 3. Metrics, traces and logs

A metric is a numeric measurement aggregated over time. Its cost depends on the number of series and not on the number of events, which makes it cheap to store and fast to evaluate, and therefore the signal on which alerts are built; the price of this economy is that a metric says that something changed but not which execution caused it. A trace records the path of one execution as a tree of spans, each one an operation with a start, an end, a parent, attributes, events and a status; it shows where the time went and where the failure happened, at the cost of one record per operation. A log records discrete events with their context; it carries the most detail, such as the text of an exception, and it is the most expensive to keep and the hardest to aggregate unless it is structured.

OpenTelemetry, the subject of the third self-study, standardises the three signals and the protocol that carries them, OTLP, so that the code is instrumented once and the stores can change. Prometheus defines the format of metrics that most tools read. The package uses both: prometheus_client for the metrics, as in the curriculum of the module, and the OpenTelemetry SDK for traces and logs.

4. Correlation: three identifiers

Three tools that do not share identifiers give three partial views, and the person on call must guess which log line belongs to which alert. The package therefore writes the same identifiers in every signal. The run_id names one run of the DataApp and is the key of ops.pipeline_runs; the trace_id names the trace of that run; the span_id names one operation inside it. Each signal carries the identifier that leads to the next, which turns an investigation into four hops.

5. Prometheus: targets, types and the push of a batch job

Prometheus collects by pulling. Every fifteen seconds it requests the endpoint /metrics of each target and stores each line as a sample of a time series, identified by a name and a set of labels. Because Prometheus initiates the scrape, it knows when a target does not answer and records it in the series up. A run of the DataApp, however, lasts about thirty seconds and has no endpoint after it ends, so it pushes its metrics to a Pushgateway, which keeps the last values of each group and is scraped in its place. The push uses pushadd, an HTTP POST that replaces only the metrics being sent, so a failed run does not erase tcg_run_last_success_timestamp_seconds, which is sent only after a success. Numbers that belong to the data rather than to a run, such as the age of the newest price, are read by an exporter, tcg-dataapp metrics, which opens the DuckDB file at each scrape.

6. Names, labels and cardinality

The name of a metric starts with the prefix of the application, tcg_, and ends with its unit in base units, _seconds, with _total closing a counter and _timestamp_seconds a moment in Unix time, so that time() - metric is an age. Each distinct combination of label values is a series that Prometheus indexes, and the number of series, the cardinality, is the product of the values of each label. The labels of the package (task, status, endpoint and measure) have at most a dozen values each. An identifier of run or of product would create a series per run or per card; such identifiers belong to the traces, to the logs and to the gold layer.

7. The telemetry module

telemetry.py owns every metric in a registry of its own, so that the tests can create as many runs as they need. RunMetrics holds the metrics of one run; InstrumentedClient wraps the client of tcgcsv.com, times each call into the histogram and, since this lesson, also opens a child span per request; WarehouseCollector reads the warehouse at each scrape and reports tcg_warehouse_readable 0 instead of failing while a run holds the DuckDB file, which accepts one writer process and no reader while it writes.

src/tcg_dataapp/telemetry.py
"""Metrics of the DataApp in the Prometheus format (traces and logs are in observability.py).

Two ways of reaching Prometheus, because the DataApp has two kinds of process:

    RunMetrics   the batch run (tcg-dataapp run) lives for about forty seconds,
                 shorter than the scrape interval, so it records its metrics while
                 it runs and pushes them to a Pushgateway at the end; it also writes
                 them to out/metrics.prom, in the text format.
    WarehouseCollector
                 the exporter (tcg-dataapp metrics) is a long-running process that
                 Prometheus scrapes; at every scrape it reads the state of the
                 warehouse (freshness, volume, grain, last run) from the DuckDB file.

Every timestamp is Unix time in seconds, which is also what Prometheus uses.
Every metric lives in a registry of its own, never in the global one, so the
tests can create as many as they need.
"""
from __future__ import annotations

import time
from pathlib import Path

import duckdb
from opentelemetry.trace import SpanKind, Status, StatusCode
from prometheus_client import CollectorRegistry, Counter, Gauge, Histogram, disable_created_metrics, generate_latest
from prometheus_client.exposition import pushadd_to_gateway
from prometheus_client.core import GaugeMetricFamily

from tcg_dataapp.observability import tracer

# The *_created series (when each counter started) only add noise to a job that lives forty seconds.
disable_created_metrics()

JOB = "tcg_dataapp"
SOURCE_BUCKETS = (0.1, 0.25, 0.5, 1, 2, 4, 8, 16)


class RunMetrics:
    """The metrics of one run of the pipeline."""

    def __init__(self, run_id: str):
        self.run_id = run_id
        self.registry = CollectorRegistry()
        r = self.registry
        self.task_attempts = Counter("tcg_task_attempts", "Attempts of each task in this run, by outcome",
                                     ["task", "status"], registry=r)
        self.task_duration = Gauge("tcg_task_duration_seconds", "Duration of the last attempt of each task",
                                   ["task"], registry=r)
        self.task_rows = Gauge("tcg_task_rows", "Rows written to db_ingestion by each extraction task", ["task"], registry=r)
        self.source_latency = Histogram("tcg_source_request_duration_seconds",
                                        "Duration of the requests to tcgcsv.com, by kind of request",
                                        ["endpoint"], buckets=SOURCE_BUCKETS, registry=r)
        self.source_errors = Counter("tcg_source_request_errors", "Requests to tcgcsv.com that raised an error",
                                     ["endpoint"], registry=r)
        self.quality = Gauge("tcg_quality_value", "Numbers measured by check_quality", ["measure"], registry=r)
        self.run_success = Gauge("tcg_run_success", "1 when every task of the run succeeded, 0 otherwise", registry=r)
        self.run_duration = Gauge("tcg_run_duration_seconds", "Duration of the whole run", registry=r)
        self.run_failed_tasks = Gauge("tcg_run_failed_tasks", "Tasks that failed or were skipped in the run", registry=r)
        # An info metric: always 1, its labels say which run (and which trace) the series above describe.
        # One series per instance, replaced at every push, so the cardinality stays at one.
        self.run_info = Gauge("tcg_run_info", "Identifiers of the last run: run_id and trace_id, to open its trace",
                              ["run_id", "trace_id"], registry=r)
        self.run_completion = Gauge("tcg_run_last_completion_timestamp_seconds",
                                    "Unix time at which the last run ended, successful or not", registry=r)
        # Pushed only after a successful run, so a failure does not erase it.
        self.success_registry = CollectorRegistry()
        self.run_last_success = Gauge("tcg_run_last_success_timestamp_seconds",
                                      "Unix time at which the last successful run ended",
                                      registry=self.success_registry)
        self.succeeded = False
        self._started = time.perf_counter()

    # hooks called by the pipeline
    def attempt(self, task: str, status: str, seconds: float | None = None, result: object = None) -> None:
        self.task_attempts.labels(task=task, status=status).inc()
        if seconds is not None:
            self.task_duration.labels(task=task).set(seconds)
        if status == "success" and task.startswith("extract_") and isinstance(result, int):
            self.task_rows.labels(task=task).set(result)
        if status == "success" and task == "check_quality" and isinstance(result, dict):
            for measure in ("fact_rows", "fact_grain_keys", "fact_without_set", "dates", "cube_cells"):
                if measure in result:
                    self.quality.labels(measure=measure).set(result[measure])

    def finish(self, failed: list[str], trace_id: str = "") -> None:
        now = time.time()
        self.run_info.labels(run_id=self.run_id, trace_id=trace_id).set(1)
        self.run_duration.set(time.perf_counter() - self._started)
        self.run_failed_tasks.set(len(failed))
        self.run_success.set(0 if failed else 1)
        self.run_completion.set(now)
        self.succeeded = not failed
        if self.succeeded:
            self.run_last_success.set(now)

    # the client of the source, wrapped so that every request is measured
    def instrument(self, client):
        return InstrumentedClient(client, self)

    # exposition
    def text(self) -> str:
        body = generate_latest(self.registry)
        if self.succeeded:
            body += generate_latest(self.success_registry)
        return body.decode()

    def write(self, path: Path) -> Path:
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(self.text(), encoding="utf-8")
        return path

    def push(self, gateway: str, instance: str = "local") -> None:
        """Push to a Pushgateway, in the group job=tcg_dataapp, instance=<instance>.

        pushadd (HTTP POST) replaces only the metrics with the names being pushed, so
        tcg_run_last_success_timestamp_seconds, pushed only after a success, keeps
        the time of the last good run when a run fails.
        """
        key = {"instance": instance}
        pushadd_to_gateway(gateway, job=JOB, registry=self.registry, grouping_key=key, timeout=10)
        if self.succeeded:
            pushadd_to_gateway(gateway, job=JOB, registry=self.success_registry, grouping_key=key, timeout=10)


class InstrumentedClient:
    """Same methods as TcgcsvClient. Each call is one child span (tcgcsv.<endpoint>), timed
    into tcg_source_request_duration_seconds and, when it raises, counted in
    tcg_source_request_errors_total and recorded in the span with status ERROR."""

    METHODS = {"groups": "groups", "products": "products", "prices_today": "prices", "prices_archive": "archive"}

    def __init__(self, client, metrics: RunMetrics):
        self._client = client
        self._metrics = metrics

    def __getattr__(self, name):
        target = getattr(self._client, name)
        endpoint = self.METHODS.get(name)
        if endpoint is None or not callable(target):
            return target

        base = getattr(self._client, "base_url", "")

        def call(*args, **kwargs):
            t0 = time.perf_counter()
            with tracer().start_as_current_span(f"tcgcsv.{endpoint}", kind=SpanKind.CLIENT,
                                                record_exception=False, set_status_on_exception=False) as span:
                span.set_attribute("http.request.method", "GET")
                span.set_attribute("server.address", base.split("//")[-1].split("/")[0])
                span.set_attribute("tcg.endpoint", endpoint)
                if args:
                    span.set_attribute("tcg.argument", str(args[0]))
                try:
                    result = target(*args, **kwargs)
                except Exception as error:
                    self._metrics.source_errors.labels(endpoint=endpoint).inc()
                    span.record_exception(error)
                    span.set_status(Status(StatusCode.ERROR, f"{type(error).__name__}: {error}"))
                    raise
                finally:
                    self._metrics.source_latency.labels(endpoint=endpoint).observe(time.perf_counter() - t0)
                size = sum(len(v) for v in result.values()) if isinstance(result, dict) else len(result)
                span.set_attribute("tcg.records", size)
                return result

        return call


class WarehouseCollector:
    """A custom collector: reads the warehouse at each scrape, as an exporter does.

    The DuckDB file accepts one writer process at a time, so while a run is
    writing the scrape cannot open it; the collector then reports
    tcg_warehouse_readable 0 instead of failing the whole scrape. The same
    happens when the file exists but the gold layer was never built.
    """

    def __init__(self, db_path: Path):
        self.db_path = Path(db_path)

    def collect(self):
        readable = GaugeMetricFamily("tcg_warehouse_readable", "1 when the exporter could read the DuckDB file at this scrape")
        if not self.db_path.exists():
            readable.add_metric([], 0)
            yield readable
            return
        try:
            con = duckdb.connect(str(self.db_path), read_only=True)
        except duckdb.Error:
            readable.add_metric([], 0)
            yield readable
            return
        try:
            families = list(self._read(con))
        except duckdb.Error:  # a warehouse without the gold layer yet, after a run that failed early
            families = []
        finally:
            con.close()
        yield from families
        readable.add_metric([], 1 if families else 0)
        yield readable

    def _read(self, con):
        rows = GaugeMetricFamily("tcg_ingestion_rows", "Rows of db_ingestion, by data tag", labels=["data_tag"])
        last = GaugeMetricFamily("tcg_ingestion_last_timestamp_seconds",
                                 "Unix time of the newest record of db_ingestion, by data tag", labels=["data_tag"])
        batches = GaugeMetricFamily("tcg_ingestion_batches", "Distinct capture timestamps, by data tag", labels=["data_tag"])
        for tag, n, newest, distinct in con.execute(
                "SELECT data_tag, count(*), max(timestamp), count(DISTINCT timestamp) FROM db_ingestion GROUP BY 1 ORDER BY 1").fetchall():
            rows.add_metric([tag], n)
            last.add_metric([tag], newest)
            batches.add_metric([tag], distinct)
        yield rows
        yield last
        yield batches

        fact_rows, fact_keys = con.execute(
            "SELECT count(*), count(DISTINCT (date_unix, product_id, variant)) FROM gold.fact_price").fetchone()
        g = GaugeMetricFamily("tcg_gold_fact_rows", "Rows of gold.fact_price")
        g.add_metric([], fact_rows)
        yield g
        g = GaugeMetricFamily("tcg_gold_fact_grain_keys", "Distinct keys (date, product, variant) of gold.fact_price")
        g.add_metric([], fact_keys)
        yield g

        status = GaugeMetricFamily("tcg_pipeline_last_run_tasks", "Task attempts of the last run in ops.pipeline_runs, by status",
                                   labels=["status"])
        ended = GaugeMetricFamily("tcg_pipeline_last_run_end_timestamp_seconds", "Unix time of the end of the last run")
        last_run = con.execute("SELECT run_id FROM ops.pipeline_runs ORDER BY started_at DESC, rowid DESC LIMIT 1").fetchone()
        if last_run:
            for st, n in con.execute("SELECT status, count(*) FROM ops.pipeline_runs WHERE run_id = ? GROUP BY 1 ORDER BY 1",
                                     [last_run[0]]).fetchall():
                status.add_metric([st], n)
            ended.add_metric([], con.execute("SELECT max(ended_at) FROM ops.pipeline_runs WHERE run_id = ?",
                                             [last_run[0]]).fetchone()[0])
        yield status
        yield ended


def exporter_registry(db_path: Path) -> CollectorRegistry:
    registry = CollectorRegistry()
    registry.register(WarehouseCollector(db_path))
    return registry

Part IIITraces and logs

8. The anatomy of a trace

A span is an operation with a name, a start and an end, a parent, attributes that describe it, events that happened inside it and a status. The spans of one execution share a trace_id and form a tree through their parents, so the tree of a run shows how its time was spent and where it failed. The package opens four kinds of span: the root tcg_dataapp.run, one task <name> per task, one tcgcsv.<endpoint> per request to the source, of kind CLIENT, and one sql <file> per SQL file of the gold layer.

A failure leaves three marks on its span. Each failed attempt adds an event "attempt failed" with the type and the message of the exception; the last one records the exception itself, with its stack; and the status becomes ERROR with a short description. Tasks skipped because a dependency failed get the attribute tcg.status = skipped, and the root ends with ERROR when any task failed. In the run with the source down, the span task extract_sets had three events "attempt failed", one per attempt, and its three child spans tcgcsv.groups were also marked ERROR.

9. The observability module

The package calls only the API of OpenTelemetry, through tracer(), which does nothing until a provider is installed. The command line installs it in setup(): a batch processor that sends spans to /v1/traces of the collector and log records to /v1/logs, both by HTTP and protobuf, and a file handler that writes the same events as JSON lines. A library never configures the SDK, because the application that uses it decides where its telemetry goes; the tests install their own provider with an in-memory exporter, once per process, which is the only number of providers OpenTelemetry accepts.

src/tcg_dataapp/observability.py
"""Traces and structured logs of the DataApp, with OpenTelemetry.

Metrics are in telemetry.py (Prometheus). This module adds the other two signals:

    traces  one span per run, one per task, and child spans for every request to
            tcgcsv.com and every SQL file of the gold layer; a failure sets the
            status of the span to ERROR and records the exception as a span event.
    logs    one JSON object per line, written to out/logs/tcg-dataapp.jsonl, with the
            run_id, the trace_id and the span_id of the span that was active when
            the line was written; with an OTLP endpoint, the same records also go
            to the collector, which delivers them to Loki.

The three signals meet in two identifiers: the run_id (in the logs, in
ops.pipeline_runs and in the metric tcg_run_info) and the trace_id (in the
spans, in the logs and in tcg_run_info). From an alert, the metric gives the
trace_id; the trace gives the failing span; the span_id gives the log line.

The rest of the package calls only the OpenTelemetry API (trace.get_tracer),
which does nothing until setup() installs a provider. So the tests install
their own provider with an in-memory exporter, and a run without a collector
still writes its JSON logs.
"""
from __future__ import annotations

import contextvars
import json
import logging
import time
from pathlib import Path

from opentelemetry import trace

from tcg_dataapp import __version__

SERVICE = "tcg-dataapp"
LOGGER = "tcg_dataapp"

# The run that is executing, so that every log line can carry it.
current_run_id: contextvars.ContextVar[str] = contextvars.ContextVar("current_run_id", default="")

# Attributes of a LogRecord that are not fields given by the caller in extra=.
_STANDARD = set(vars(logging.LogRecord("", 0, "", 0, "", (), None))) | {"message", "asctime", "taskName"}


def tracer():
    return trace.get_tracer(LOGGER, __version__)


def logger() -> logging.Logger:
    return logging.getLogger(LOGGER)


def ids() -> tuple[str, str]:
    """(trace_id, span_id) of the active span, in hexadecimal, or ("", "") outside a span."""
    ctx = trace.get_current_span().get_span_context()
    if not ctx.is_valid:
        return "", ""
    return f"{ctx.trace_id:032x}", f"{ctx.span_id:016x}"


class JsonFormatter(logging.Formatter):
    """One JSON object per line: time in Unix seconds, level, message, run and trace context, extra fields."""

    def format(self, record: logging.LogRecord) -> str:
        trace_id, span_id = ids()
        line = {
            "ts": round(record.created, 3),
            "level": record.levelname.lower(),
            "logger": record.name,
            "msg": record.getMessage(),
            "service": SERVICE,
            "run_id": current_run_id.get(),
            "trace_id": trace_id,
            "span_id": span_id,
        }
        for key, value in vars(record).items():
            if key not in _STANDARD and key not in line:
                line[key] = value if isinstance(value, (str, int, float, bool)) or value is None else str(value)
        if record.exc_info:
            line["exception"] = self.formatException(record.exc_info)
        return json.dumps(line, ensure_ascii=False)


class RunIdFilter(logging.Filter):
    """Adds run_id as an attribute of every record, so that the OTLP handler exports it too."""

    def filter(self, record: logging.LogRecord) -> bool:
        if not getattr(record, "run_id", ""):
            record.run_id = current_run_id.get()
        return True

10. Structured logs inside their span

A log line in free text is read by a person; a structured line is read by a machine as well, because each field has a name. The JsonFormatter writes one JSON object per line with the time in Unix seconds, the level, the message, the service, the run_id taken from a context variable, and the trace_id and span_id of the span active at the moment of the call. The pipeline writes each line inside the span it describes, which is what makes the span_id of the line equal to the span_id of the failing task.

a line of out/logs/tcg-dataapp.jsonl, from the run with the source down
{"ts": 1794146686.73, "level": "error", "logger": "tcg_dataapp", "msg": "task attempt failed",
 "service": "tcg-dataapp", "run_id": "e44b5b8a34eb", "trace_id": "5d1d493014dd2ecc409d7593266173a2",
 "span_id": "ba8fc2d7eb92ef1c", "event": "task.fail", "task": "extract_sets", "attempt": 2,
 "attempts": 3, "error": "ConnectionError: fault injected: source_down"}

Five events cover a run: run.start, task.ok, task.fail, task.skip and run.end. A line never carries records of the source, only counts and errors, so the logs can be kept and shared without the data. When the OTLP endpoint is configured, the same records go to Loki, which keeps the attributes as structured metadata and filters them after the stream selector.

11. The instrumented pipeline

The pipeline opens the root span, sets the run_id in the context variable and runs each task inside its own span, adding the events, the status and the log lines described above. At the end of a successful run it records each batch of db_ingestion, with its rows and an md5 digest of its content, in ops.good_batches: the last known good state that the controller of Part V restores. The trace_id of the run is passed to the metrics, where it becomes the label of tcg_run_info.

src/tcg_dataapp/pipeline.py

Each task is a function of the run context. A task runs only after all the
tasks it depends on succeeded; a failure is retried, and a task that still
fails stops every task that depends on it. Every attempt is recorded in
ops.pipeline_runs, with Unix times, so a run can be audited afterwards.

Lesson 10: the run emits the three signals of observability.

    metrics  a telemetry.RunMetrics object (attempts, durations, rows, requests to
             the source, quality numbers, outcome, and tcg_run_info with the

    traces   a root span tcg_dataapp.run, one span per task, and the child spans

def build_tasks(settings: Settings, with_today: bool = False) -> list[Task]:
    tasks = [
        Task("extract_sets", lambda c: extract.extract_sets(c.con, c.client, c.settings.sets, c.captured_at)),
        Task("extract_products", lambda c: extract.extract_products(c.con, c.client, c.settings.sets, c.captured_at),
             depends_on=("extract_sets",)),
    ]
    price_tasks = []
    for day in settings.price_dates:
        name = f"extract_prices_{day}"
        tasks.append(Task(name, lambda c, d=day: extract.extract_prices_archive(c.con, c.client, c.settings.sets, d),
                          depends_on=("extract_products",)))
        price_tasks.append(name)
    if with_today:
        tasks.append(Task("extract_prices_today",
                          lambda c: extract.extract_prices_today(c.con, c.client, c.settings.sets, extract.today()),
                          depends_on=("extract_products",)))
        price_tasks.append("extract_prices_today")
    tasks += [
        Task("build_gold", lambda c: gold.build_gold(c.con), depends_on=tuple(price_tasks), retries=0),
        Task("check_quality", lambda c: quality.check_gold(c.con), depends_on=("build_gold",), retries=0),
        Task("freeze_reports", lambda c: gold.freeze_month(c.con, c.settings.frozen_month),
             depends_on=("check_quality",), retries=0),
        Task("export_marts", lambda c: [p.as_posix() for p in report.export_marts(c.con, c.settings.out_dir)],
             depends_on=("check_quality",)),
        Task("write_report", lambda c: report.write_report(c.con, c.settings.out_dir, c.run_id).as_posix(),
             depends_on=("freeze_reports", "export_marts")),
    ]
    return tasks


def order(tasks: list[Task]) -> list[Task]:
    """Topological order of the tasks; raises on an unknown dependency or a cycle."""
    by_name = {t.name: t for t in tasks}
    for t in tasks:
        for d in t.depends_on:
            if d not in by_name:
                raise ValueError(f"task {t.name} depends on unknown task {d}")
    done, ordered, visiting = set(), [], set()

    def visit(t: Task):
        if t.name in done:
            return
        if t.name in visiting:
            raise ValueError(f"cycle at task {t.name}")
        visiting.add(t.name)
        for d in t.depends_on:
            visit(by_name[d])
        visiting.discard(t.name)
        done.add(t.name)
        ordered.append(t)

    for t in tasks:
        visit(t)
    return ordered


def _log(con, run_id, task, attempt, status, started, ended, detail):
    con.execute("INSERT INTO ops.pipeline_runs VALUES (?, ?, ?, ?, ?, ?, ?)",
                [run_id, task, attempt, status, started, ended, str(detail)[:500]]).fetchall()


def record_good_state(con, run_id: str) -> int:
    """Replace ops.good_batches with the batches present now; returns how many."""
    con.execute("DELETE FROM ops.good_batches").fetchall()
    con.execute(f"INSERT INTO ops.good_batches SELECT data_tag, timestamp, rows, digest, ?, ? FROM ({BATCH_DIGEST})",
                [run_id, extract.now_unix()]).fetchall()
    return con.execute("SELECT count(*) FROM ops.good_batches").fetchone()[0]


def _summary(result) -> str:
    return str(result)[:200]


def run(settings: Settings, tasks: list[Task] | None = None, client: TcgcsvClient | None = None,
        con: duckdb.DuckDBPyConnection | None = None, with_today: bool = False,
        echo: Callable[[str], None] = print, metrics: bool = True, trigger: str = "manual") -> Context:
    own = con is None
    if own:
        settings.db_path.parent.mkdir(parents=True, exist_ok=True)
        con = duckdb.connect(str(settings.db_path))
    for statement in con.extract_statements(LOG_DDL):
        con.execute(statement).fetchall()
    run_id = uuid.uuid4().hex[:12]
    token = current_run_id.set(run_id)
    log = logger()
    m = RunMetrics(run_id) if metrics else None
    source = client or TcgcsvClient(settings.base_url, settings.category)
    if settings.fault:
        from tcg_dataapp.faults import FaultyClient
        source = FaultyClient(source, settings.fault)
    ctx = Context(settings=settings, con=con, client=m.instrument(source) if m else source,
                  run_id=run_id, captured_at=extract.now_unix(), metrics=m)
    failed: set[str] = set()
    t_run = time.perf_counter()
    try:
        with tracer().start_as_current_span("tcg_dataapp.run") as root:
            root.set_attribute("tcg.run_id", run_id)
            root.set_attribute("tcg.trigger", trigger)
            root.set_attribute("tcg.sets", len(settings.sets))
            root.set_attribute("tcg.with_today", with_today)
            if settings.fault:
                root.set_attribute("tcg.fault", settings.fault)
            ctx.trace_id = ids()[0]
            log.info("run started", extra={"event": "run.start", "trigger": trigger, "fault": settings.fault})
            for task in order(tasks or build_tasks(settings, with_today)):
                _run_task(ctx, task, failed, echo)
            ctx.results["_failed"] = sorted(failed)
            if failed:
                root.set_status(Status(StatusCode.ERROR, f"failed: {', '.join(sorted(failed))}"))
            else:
                ctx.results["_good_batches"] = record_good_state(con, run_id)
            root.set_attribute("tcg.failed_tasks", len(failed))
            log.log(40 if failed else 20, "run finished", extra={
                "event": "run.end", "status": "failed" if failed else "ok", "failed_tasks": ",".join(sorted(failed)),
                "duration_s": round(time.perf_counter() - t_run, 3)})
    finally:
        if own:
            con.close()
        current_run_id.reset(token)
    if m:
        m.finish(ctx.results["_failed"], ctx.trace_id)
    return ctx


def _run_task(ctx: Context, task: Task, failed: set, echo) -> None:
    con, settings, m, log = ctx.con, ctx.settings, ctx.metrics, logger()
    with tracer().start_as_current_span(f"task {task.name}") as span:
        span.set_attribute("tcg.task", task.name)
        if any(d in failed for d in task.depends_on):
            failed.add(task.name)
            span.set_attribute("tcg.status", "skipped")
            span.set_status(Status(StatusCode.ERROR, "a dependency failed"))
            _log(con, ctx.run_id, task.name, 0, "skipped", extract.now_unix(), extract.now_unix(), "a dependency failed")
            log.warning("task skipped", extra={"event": "task.skip", "task": task.name})
            echo(f"  skip  {task.name}  (a dependency failed)")
            if m:
                m.attempt(task.name, "skipped")
            return
        attempts = 1 + (settings.retries if task.retries is None else task.retries)
        for attempt in range(1, attempts + 1):
            started = extract.now_unix()
            t0 = time.perf_counter()
            try:
                result = task.run(ctx)
            except Exception as error:  # noqa: BLE001 - every failure is logged and retried
                detail = f"{type(error).__name__}: {error}"
                _log(con, ctx.run_id, task.name, attempt, "failed", started, extract.now_unix(), detail)
                span.add_event("attempt failed", {"tcg.attempt": attempt, "exception.type": type(error).__name__,
                                                  "exception.message": str(error)[:300]})
                log.error("task attempt failed", extra={"event": "task.fail", "task": task.name, "attempt": attempt,
                                                        "attempts": attempts, "error": detail[:300]})
                if m:
                    m.attempt(task.name, "failed", time.perf_counter() - t0)
                echo(f"  fail  {task.name}  attempt {attempt}/{attempts}: {detail}")
                if attempt == attempts:
                    failed.add(task.name)
                    span.record_exception(error)
                    span.set_status(Status(StatusCode.ERROR, detail[:200]))
                    span.set_attribute("tcg.status", "failed")
                else:
                    time.sleep(settings.retry_delay * attempt)
                continue
            seconds = time.perf_counter() - t0
            ctx.results[task.name] = result
            _log(con, ctx.run_id, task.name, attempt, "success", started, extract.now_unix(), result)
            span.set_attribute("tcg.status", "success")
            span.set_attribute("tcg.attempts", attempt)
            span.set_attribute("tcg.result", _summary(result))
            log.info("task succeeded", extra={"event": "task.ok", "task": task.name, "attempt": attempt,
                                              "duration_s": round(seconds, 3), "result": _summary(result)})
            if m:
                m.attempt(task.name, "success", seconds, result)
            echo(f"  ok    {task.name}  {seconds:5.2f} s  {result}")
            return

15. Alerts on symptoms, tested

An alerting rule is a PromQL expression that creates an alert while it returns series. Each rule of the lab describes a symptom that someone must act on, with a threshold that comes from how the DataApp runs: a failed run, no success for 26 hours (a daily run plus two hours), prices older than 36 hours, a run over 120 seconds (three times the reference), rows above the grain, and an exporter that cannot read the warehouse for two minutes. The description of TcgRunFailed uses the template function query to read tcg_run_info, so the alert itself carries the run and the trace. Three more rules cover the controller of Part V: an escalation, a breaker open for two hours and a controller that stopped ticking.

17. The elements of a closed loop

Control theory describes a closed loop as a process whose output is measured and compared with a reference, so that the difference drives an action on the process. The reference is the setpoint; the measurement comes from a sensor; the comparator subtracts one from the other and produces the error; the controller turns the error into a decision; the actuator applies the decision to the process, which the theory calls the plant; and the new measurement returns to the comparator, which is the feedback that gives the loop its name. In site reliability engineering the setpoint is a service level objective (SLO) and the measurement a service level indicator (SLI).

18. Observability alone is not a closed loop

The first three steps of the session built a sensor and a display. Metrics, traces and logs measure the DataApp, and Grafana and the alerts show the measurement. Nothing in them compares the measurement with the objective and acts on the DataApp: an alert hands that decision to a person. The loop is then closed by a human, which is slow, depends on someone being awake and available, and degrades with fatigue, nights and holidays. It is also intermittent, because between the alert and the action the DataApp keeps serving stale or wrong data. A scheduler that runs the DataApp every morning is an open loop: it acts without measuring, and repeats the same action whether the previous one worked or not.

Closing the loop does not remove the person. The controller acts only on failures that have a known and safe action, and escalates, once, everything that persists or has no actuator. Observability remains necessary in the closed loop, as its sensor, and becomes the record of what the controller did, because each decision is itself a span, a log line and a metric.

19. Stability: hysteresis, backoff and guardrails

An automatic action changes the process that the sensor reads next, and a badly designed loop oscillates or amplifies the failure. A threshold crossed back and forth turns an action on and off at every tick; a rerun against a source that is down fails again and adds load to a system that is already failing; an action repeated without limit hides a failure that is not transient. The controller of the lab has a guardrail for each of these modes.

20. The controller

control.py implements the loop in four functions and one class. sense() reads the SLIs and classifies the error of the last run as a failure of the source, of quality or of another kind. errors() subtracts the setpoints. decide() chooses one action with no access to the database or to the clock, so every rule has a test with a fake clock. quarantine() moves every batch that is not in ops.good_batches, compared by rows and digest, to quarantine.db_ingestion, rebuilds the views of gold and checks them; the frozen reports are tables and are not touched. Observability alone is the sensor and the display of the loop: the metrics, traces
and logs say what happened, and an alert tells a person. The loop closes only
when something compares the measured value with the setpoint and acts on the
process. This module is that something, in the vocabulary of control theory:

    setpoint    the SLOs of config.py (freshness, success, duration, source errors, grain)
    sensor      sense(): the SLIs read from the warehouse (db_ingestion, gold, ops.pipeline_runs)

def sense(con, now: float) -> Sli:
    """The sensor: SLIs read from the warehouse, the same numbers that the exporter publishes."""
    s = Sli()
    try:
        newest = con.execute("SELECT max(timestamp) FROM db_ingestion WHERE data_tag = 'tcgplayer.price.v1'").fetchone()[0]
    except duckdb.Error:
        newest = None
    s.freshness_s = None if newest is None else max(now - newest, 0)
    last = con.execute("SELECT run_id FROM ops.pipeline_runs ORDER BY started_at DESC, rowid DESC LIMIT 1").fetchone()
    if last:
        s.last_run_id = last[0]
        rows = con.execute("SELECT task, attempt, status, started_at, ended_at, detail FROM ops.pipeline_runs "
                           "WHERE run_id = ? ORDER BY started_at, attempt", [s.last_run_id]).fetchall()
        final = {}
        for task, _attempt, status, *_ in rows:
            final[task] = status
        s.failed_tasks = sorted(t for t, st in final.items() if st in ("failed", "skipped"))
        s.last_status = "failed" if s.failed_tasks else "ok"
        s.run_duration_s = max(r[4] for r in rows) - min(r[3] for r in rows)
        extract_attempts = [r for r in rows if r[0].startswith("extract_") and r[2] in ("success", "failed")]
        source_failures = [r for r in extract_attempts if r[2] == "failed" and str(r[5]).startswith(SOURCE_ERRORS)]
        s.source_error_rate = len(source_failures) / len(extract_attempts) if extract_attempts else 0
        roots = [t for t, st in final.items() if st == "failed"]
        if any(t in QUALITY_TASKS for t in roots):
            s.error_class = "quality"
        elif roots and all(t.startswith("extract_") for t in roots) and source_failures:
            s.error_class = "source"
        elif roots:
            s.error_class = "other"
    try:
        rows, keys = con.execute("SELECT count(*), count(DISTINCT (date_unix, product_id, variant)) FROM gold.fact_price").fetchone()
        s.grain_ok = rows == keys
    except duckdb.Error:
        s.grain_ok = None
    return s


def errors(sli: Sli, st: Settings) -> dict:
    """The comparator: SLI minus setpoint; a positive error is a violation."""
    return {
        "freshness_s": None if sli.freshness_s is None else sli.freshness_s - st.slo_freshness_s,
        "run_duration_s": sli.run_duration_s - st.slo_run_duration_s,
        "source_error_rate": round(sli.source_error_rate - st.slo_source_error_rate, 4),
        "run_failed": 1 if sli.last_status == "failed" else 0,
        "grain_broken": 1 if sli.grain_ok is False else 0,
    }


def stale_with_hysteresis(sli: Sli, state: State, st: Settings) -> bool:
    """Enter the stale state above slo_freshness_s and leave it only below slo_freshness_ok_s.

    Without the dead band, a freshness that hovers around the setpoint would
    turn the reruns on and off at every tick.
    """
    if sli.freshness_s is None:
        return True
    if sli.freshness_s > st.slo_freshness_s:
        return True
    if sli.freshness_s < st.slo_freshness_ok_s:
        return False
    return state.stale


def decide(sli: Sli, state: State, st: Settings, now: float, history: list[tuple]) -> Decision:
    """The controller: a pure function, so every rule can be tested with a fake clock.

    history is the list of (at, action) of ops.controller_actions inside the window.
    """
    stale = stale_with_hysteresis(sli, state, st)
    state.stale = stale
    quality_bad = sli.grain_ok is False or (sli.last_status == "failed" and sli.error_class == "quality")
    source_bad = sli.last_status == "failed" and (sli.error_class == "source"
                                                  or sli.source_error_rate > st.slo_source_error_rate)
    run_failed = sli.last_status == "failed"
    healthy = not (stale or quality_bad or run_failed)

    if healthy:
        if state.breaker != "closed" or state.escalated or state.opens:
            return Decision("resolve", "every SLI is within its SLO")
        return Decision("none", "every SLI is within its SLO")

    # Protection comes before everything, even with an open escalation: a broken
    # gold layer is quarantined at once, so the views never serve a wrong number.
    if quality_bad and sli.last_run_id != state.handled_run:
        strikes = sum(1 for _, a in history if a == "quarantine") + 1
        return Decision("quarantine", f"quality gate failed in run {sli.last_run_id} ({', '.join(sli.failed_tasks)})",
                        escalate=strikes >= 2)

    if state.escalated:
        return Decision("hold", f"escalated ({state.escalated}); waiting for a person")

    if state.breaker == "open":
        if now < state.open_until:
            return Decision("hold", f"circuit breaker open for {int(state.open_until - now)} s more")
        return Decision("probe", "backoff elapsed; probing the source")

    if source_bad:
        return Decision("open_breaker", f"the source failed: error rate {sli.source_error_rate:.0%} "
                                        f"against an SLO of {st.slo_source_error_rate:.0%}")

    reruns = [at for at, a in history if a == "rerun"]
    if len(reruns) >= st.control_max_actions:
        return Decision("escalate", f"{len(reruns)} reruns in {st.control_window_s} s did not restore the SLOs")
    if reruns and now - max(reruns) < st.control_cooldown_s:
        return Decision("hold", f"cooldown: last rerun {int(now - max(reruns))} s ago")
    if run_failed:
        return Decision("rerun", f"run {sli.last_run_id} failed ({sli.error_class}: {', '.join(sli.failed_tasks)})")
    return Decision("rerun", f"prices are {int(sli.freshness_s or 0)} s old, SLO {st.slo_freshness_s} s")


def quarantine(con, run_id: str, reason: str, now: float) -> dict:
    """Move every batch that is not in the last known good state to quarantine.db_ingestion.

    A batch is good when its tag, timestamp, rows and digest are those recorded by
    the last successful run in ops.good_batches. Removing the others brings
    db_ingestion back to that state, so the views of gold (rebuilt and checked
    here) serve the last good numbers again; the frozen reports are tables and
    are not touched. The quarantined rows stay available for a person to inspect.
    """
    good = con.execute("SELECT count(*) FROM ops.good_batches").fetchone()[0]
    if not good:
        raise RuntimeError("no known good state to restore")
    con.execute("CREATE OR REPLACE TEMP TABLE _digest AS " + pipeline.BATCH_DIGEST).fetchall()
    bad = con.execute("""
        SELECT d.data_tag, d.timestamp FROM _digest d
        LEFT JOIN ops.good_batches g USING (data_tag, timestamp)
        WHERE g.data_tag IS NULL OR g.rows IS DISTINCT FROM d.rows OR g.digest IS DISTINCT FROM d.digest
    """).fetchall()
    moved = 0
    con.execute("BEGIN TRANSACTION").fetchall()
    try:
        for tag, ts in bad:
            moved += con.execute("SELECT count(*) FROM db_ingestion WHERE data_tag = ? AND timestamp = ?", [tag, ts]).fetchone()[0]
            con.execute("INSERT INTO quarantine.db_ingestion SELECT timestamp, data_json, data_tag, ?, ?, ? "
                        "FROM db_ingestion WHERE data_tag = ? AND timestamp = ?", [run_id, reason[:300], int(now), tag, ts]).fetchall()
            con.execute("DELETE FROM db_ingestion WHERE data_tag = ? AND timestamp = ?", [tag, ts]).fetchall()
        con.execute("COMMIT").fetchall()
    except Exception:
        con.execute("ROLLBACK").fetchall()
        raise
    gold.build_gold(con)
    checked = quality.check_gold(con)
    return {"batches": len(bad), "rows": moved, "fact_rows": checked["fact_rows"], "grain_keys": checked["fact_grain_keys"]}

def _connect(path, tries: int = 5, pause: float = 0.5):
    """Open the warehouse for writing; the exporter may be reading it for a few milliseconds."""
    for attempt in range(tries):
        try:
            return duckdb.connect(str(path))
        except duckdb.IOException:
            if attempt == tries - 1:
                raise
            time.sleep(pause)


class Controller:
    def __init__(self, settings: Settings, client_factory: Callable[[], object] | None = None,
                 now: Callable[[], float] = time.time, echo: Callable[[str], None] = print):
        self.settings = settings
        self.client_factory = client_factory or (lambda: TcgcsvClient(settings.base_url, settings.category))
        self.now = now
        self.echo = echo

    def tick(self) -> Decision:
        st, now, log = self.settings, self.now(), logger()
        st.db_path.parent.mkdir(parents=True, exist_ok=True)
        con = _connect(st.db_path)
        tick_id = uuid.uuid4().hex[:12]
        try:
            for statement in con.extract_statements(pipeline.LOG_DDL + STATE_DDL):
                con.execute(statement).fetchall()
            with tracer().start_as_current_span("control.tick") as span:
                span.set_attribute("tcg.tick_id", tick_id)
                state = State.load(con)
                with tracer().start_as_current_span("control.sense"):
                    sli = sense(con, now)
                err = errors(sli, st)
                history = con.execute("SELECT acted_at, action FROM ops.controller_actions WHERE acted_at >= ? ORDER BY acted_at",
                                      [int(now - st.control_window_s)]).fetchall()
                decision = decide(sli, state, st, now, history)
                for k, v in asdict(sli).items():
                    if isinstance(v, (int, float, str, bool)):
                        span.set_attribute(f"tcg.sli.{k}", v)
                span.set_attribute("tcg.decision", decision.action)
                span.set_attribute("tcg.reason", decision.reason)
                outcome = self._act(con, decision, state, sli, now)
                if decision.escalate and not state.escalated:
                    outcome += " · " + self._escalate(con, state, decision.reason, now)
                if decision.action in ("open_breaker", "quarantine", "escalate", "probe") and "fail" in outcome:
                    span.set_status(Status(StatusCode.ERROR, outcome[:200]))
                state.save(con, now)
                trace_id = ids()[0]
                if decision.action != "none":
                    con.execute("INSERT INTO ops.controller_actions VALUES (?, ?, ?, ?, ?, ?)",
                                [tick_id, int(now), decision.action, decision.reason[:300], outcome[:300], trace_id]).fetchall()
                level = 20 if decision.action in ("none", "hold", "resolve") else 30
                if state.escalated and decision.action == "escalate":
                    level = 40
                log.log(level, "control tick", extra={
                    "event": "control.tick", "tick_id": tick_id, "action": decision.action, "reason": decision.reason,
                    "outcome": outcome, "breaker": state.breaker, "escalated": state.escalated,
                    "freshness_s": sli.freshness_s, "last_run": sli.last_run_id, "last_status": sli.last_status,
                    "error_class": sli.error_class, "grain_ok": sli.grain_ok})
                self.echo(f"tick {tick_id}  {decision.action:12} {decision.reason}  →  {outcome}")
                self._push(con, sli, err, state, now)
        finally:
            con.close()
        return decision

    # actuators
    def _act(self, con, d: Decision, state: State, sli: Sli, now: float) -> str:
        st = self.settings
        with tracer().start_as_current_span(f"control.act {d.action}") as span:
            if d.action in ("none", "hold"):
                return "no action"
            if d.action == "resolve":
                closed = f"breaker {state.breaker} → closed" if state.breaker != "closed" else "breaker closed"
                was = state.escalated
                state.breaker, state.open_until, state.opens, state.escalated = "closed", 0, 0, ""
                return closed + (f"; escalation resolved ({was})" if was else "")
            if d.action == "rerun":
                return self._rerun(con, span)
            if d.action == "open_breaker":
                return self._open(state, now)
            if d.action == "probe":
                try:
                    with tracer().start_as_current_span("control.probe"):
                        client = self.client_factory()
                        if st.fault:                       # a rehearsed fault applies to the probe too
                            from tcg_dataapp.faults import FaultyClient
                            client = FaultyClient(client, st.fault)
                        client.groups()
                except Exception as error:  # noqa: BLE001 - a failed probe reopens the breaker
                    span.record_exception(error)
                    result = f"probe failed ({type(error).__name__}); " + self._open(state, now)
                    if state.opens >= st.breaker_max_opens and not state.escalated:
                        result += " · " + self._escalate(con, state, f"source down after {state.opens} openings of the breaker", now)
                    return result
                state.breaker, state.open_until = "closed", 0
                return "probe ok, breaker closed; " + self._rerun(con, span)
            if d.action == "quarantine":
                try:
                    q = quarantine(con, sli.last_run_id, d.reason, now)
                except Exception as error:  # noqa: BLE001
                    span.record_exception(error)
                    return "quarantine failed: " + self._escalate(con, state, f"cannot restore a good state: {error}", now)
                state.handled_run = sli.last_run_id
                return (f"{q['batches']} batches ({q['rows']} rows) quarantined; gold back to the last good state, "
                        f"{q['fact_rows']} rows = {q['grain_keys']} keys")
            if d.action == "escalate":
                return self._escalate(con, state, d.reason, now)
        return "unknown action"

    def _rerun(self, con, span) -> str:
        ctx = pipeline.run(self.settings, client=self.client_factory(), con=con, with_today=True,
                           echo=lambda _: None, trigger="controller")
        failed = ctx.results["_failed"]
        span.set_attribute("tcg.rerun.run_id", ctx.run_id)
        if self.settings.pushgateway and ctx.metrics:
            try:
                ctx.metrics.push(self.settings.pushgateway, self.settings.instance)
            except OSError:
                pass
        return f"rerun {ctx.run_id} " + ("ok" if not failed else f"failed ({', '.join(failed)})")

    def _open(self, state: State, now: float) -> str:
        backoff = self.settings.breaker_backoff_s * 2 ** state.opens
        state.breaker, state.open_until, state.opens = "open", now + backoff, state.opens + 1
        return f"breaker open for {backoff} s (opening {state.opens})"

    def _escalate(self, con, state: State, reason: str, now: float) -> str:
        """Hand the loop to a person: once, until the SLIs are back within the SLOs."""
        state.escalated = reason[:200]
        url = self.settings.escalation_webhook
        if url:
            body = json.dumps({"service": "tcg-dataapp", "reason": reason, "at": int(now), "trace_id": ids()[0]}).encode()
            try:
                urllib.request.urlopen(urllib.request.Request(url, data=body, headers={"Content-Type": "application/json"}),
                                       timeout=5).read()
            except OSError:
                return "escalated (webhook unreachable; the metric tcg_controller_escalated still pages)"
        return "escalated to a person"

    def _push(self, con, sli: Sli, err: dict, state: State, now: float) -> None:
        if not self.settings.pushgateway:
            return
        m = ControllerMetrics(con)
        st = self.settings
        for name, value, slo in (("freshness_s", sli.freshness_s, st.slo_freshness_s),
                                 ("run_duration_s", sli.run_duration_s, st.slo_run_duration_s),
                                 ("source_error_rate", sli.source_error_rate, st.slo_source_error_rate)):
            if value is not None:
                m.sli.labels(sli=name).set(value)
                m.slo.labels(sli=name).set(slo)
                m.error.labels(sli=name).set(err[name])
        m.sli.labels(sli="grain_ok").set(1 if sli.grain_ok else 0)
        m.breaker.set(1 if state.breaker == "open" else 0)
        m.escalated.set(1 if state.escalated else 0)
        m.tick.set(now)
        try:
            pushadd_to_gateway(st.pushgateway, job="tcg_controller", registry=m.registry,
                               grouping_key={"instance": st.instance}, timeout=10)
        except OSError:
            pass

    def loop(self, interval: float, ticks: int | None = None, sleep: Callable[[float], None] = time.sleep) -> None:
        n = 0
        while ticks is None or n < ticks:
            self.tick()
            n += 1
            if ticks is None or n < ticks:
                sleep(interval)

22. The same idea at scale

The controller of the DataApp is small, but its structure is that of the control loops that run most production systems. Each Kubernetes controller runs a reconciliation loop: it compares the desired state declared in a resource with the observed state and acts until they match, so a Deployment of three replicas recreates a pod that died. The Horizontal Pod Autoscaler has a setpoint in CPU or in a custom metric, a sensor in the metrics API, an actuator on the number of replicas, and a stabilisation window against oscillation. Alertmanager can deliver an alert to a webhook that runs a remediation for a known failure, with routing, grouping and silences as guardrails. The error budget of site reliability engineering closes a loop on the work of a team: while the SLO leaves budget, changes go out, and when the budget is spent, releases stop until reliability recovers.

26. What the rehearsal revealed

Five problems appeared only when the reference ran against real data and a real stack, and the prompts and the reference already carry their corrections.

A batch replaced by the same key

The prices of today are loaded as the batch of noon UTC, so a run with duplicated prices replaced the good batch of the same day instead of adding a new one. A good state recorded only by key would not detect it, which is why ops.good_batches keeps the rows and an md5 digest of each batch. The consequence is that the quarantine cannot restore the replaced content: gold falls back to the previous captures, 5,951 rows, until a good run brings today back.

The window of the escalation

In the rehearsal, the persistent bad batch escalated at its first quarantine, because the quarantine of the transient case had happened less than six hours before. The rule counts quarantines in the window, not per fault, which is the intended behaviour: two bad batches in six hours are a pattern that a person should see.

Two runs in the same second

The tests ran a good run and a failed run within the same second, and the sensor, which looked for the last run by its start time, sometimes read the good one. The last run is now chosen by start time and then by insertion order.

A reserved word

The first version of ops.controller_actions had a column named at, which DuckDB rejects as a reserved word; it is acted_at.

Explore closed to viewers

With anonymous access as Viewer, Grafana redirected every link to Explore back to the dashboard, so the links from the metric to the trace did nothing. The stack sets GF_USERS_VIEWERS_CAN_EDIT, acceptable on a local stack and not on a shared one.

27. The second hour

In the second hour each group applies the method to its own DataApp, the package of Lesson 7 or the flow of Lesson 8, with prompt 05. The result expected at the end of the session has two parts. The first is the three signals with the identifiers that link them, three alerting rules tested with promtool, and a failure rehearsed on purpose and followed from the alert to the log line. The second is one SLO of the DataApp with its closed loop: the setpoint and the dead band, the sensor, the actuator and what it changes, the cooldown, the budget and the condition to escalate, and a test that breaks the DataApp and proves that the loop recovers or escalates once. When an SLO has no safe actuator, the group states it, and that SLO stays as an alert to a person.

29. Checklist

  • Every metric has the prefix of the application and its unit in the name, and no label takes an identifier.
  • The run and its trace are named by one info metric.
  • A run is one trace, with one span per task, per call to the source and per transformation.
  • A failure sets the status of its span, records the exception and its attempts.
  • Every log line is JSON and carries run_id, trace_id and span_id.
  • The application sends traces and logs to one collector.
  • From an alert, a person reaches the log line of the failing span in four hops.
  • Every alert describes a symptom, has a reason for its threshold and a promtool test.
  • Each SLO declares whether it has an actuator; if not, it is an alert to a person.
  • The loop has hysteresis, a cooldown, a budget per window and one escalation.
  • A test breaks the DataApp and proves that the loop recovers or escalates once.
  • Every action of the controller is a span, a log line and a metric.
