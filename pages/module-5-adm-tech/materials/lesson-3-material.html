Sobre este encontro

Python e Pandas para Leitura de Planilhas · Prof. Afonso

Objetivo de aprendizagem

Ao final do encontro, o estudante deve ser capaz de aplicar ao projeto os conceitos de Python e Pandas para Leitura de Planilhas. Escopo do encontro: Utilize Python e Pandas para ler, processar e analisar dados de planilhas de forma eficiente.

Estratégia do encontro

Exposição dialogada dos conceitos, alternada com aplicação guiada ao projeto do grupo, e fechamento com verificação do entendimento.
