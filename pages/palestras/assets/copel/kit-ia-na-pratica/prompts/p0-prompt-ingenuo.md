# Prompt 0: a versão ingênua

Use este prompt exatamente como está, anexando os dois arquivos da pasta `benchmark/`: o
relatório (`relatorio-benchmark-ia-distribuicao.md`) e a planilha (`indicadores-distribuidoras.csv`).
Se a ferramenta não aceitar esses formatos, use as versões `.docx` e `.xlsx` dos mesmos arquivos; se ela não aceitar anexos, cole o conteúdo dos dois arquivos abaixo do prompt, depois de uma linha `## DADOS`. Desligue a busca na web e a memória entre conversas, ou use conversa temporária, se a ferramenta oferecer essas opções.
Este prompt serve de linha de base, e a saída dele será comparada com a do prompt estruturado.

```
Analise esse benchmark de distribuidoras e me diga quais são as melhores práticas de IA
que a gente deveria adotar.
```

Guarde a resposta inteira, sem editar, no `documento-do-grupo.docx`.
