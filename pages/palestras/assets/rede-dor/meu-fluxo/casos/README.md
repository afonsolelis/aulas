# Casos

Crie uma pasta por caso, por exemplo `casos/2026-09-teste/`, com os arquivos de entrada e uma cópia de `modelos/estado.md`. Use dados fictícios ou anonimizados; dado real de paciente não entra neste repositório de treino.

Antes de levar o fluxo à rotina, guarde aqui dois ou três casos já resolvidos, com o resultado conhecido, e execute o fluxo sobre eles a cada alteração de agente ou skill.
