Sobre a disciplina

Oito aulas práticas que vão da coleta ao dado validado: tipos de storage, object storage com MinIO, APIs REST e web scraping, ingestão com fila, DuckDB e ClickHouse, modelagem dimensional, streaming e testes integrados. Em cada aula o professor constrói o projeto ao vivo e cada aluno reproduz o mesmo caminho no próprio repositório.

Método e ambiente
📐 Método:
Spec-Driven Development e prompts no formato CREATE
💻 Ambiente:
GitHub Codespaces ou máquina local, com Docker
🤖 Agente:
agente de código de preferência do aluno, guiado pelo AGENTS.md
☁️ Publicação:
Railway para MinIO, Postgres, RabbitMQ e ClickHouse

Tipos de Storage e Coleta em Object Storage com MinIO

📅 Aula 02 · 17/10/2026

Armazenamento em bloco, arquivo, objeto e banco, com os trade-offs de cada um. Telemetria de caminhões em TXT para comparar file e object storage e separar storage, data lake, lakehouse e data warehouse. Coletor dos lotes TXT gravando o bruto no MinIO, com chave particionada e idempotência, e discussão de três decisões sobre a arquitetura.

Arquitetura de Ingestão com Fila, DuckDB e ClickHouse
