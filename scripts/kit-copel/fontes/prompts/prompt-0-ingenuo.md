# Prompt 0: a versão ingênua

Use este prompt exatamente como está, em uma conversa nova, anexando três arquivos: a minuta
(proposta-a-ia-perdas.docx), o relatório do benchmark (relatorio-benchmark-ia-distribuicao.docx)
e a planilha de indicadores (indicadores-distribuidoras.xlsx). Se a ferramenta não aceitar
anexos, copie o conteúdo dos arquivos e cole abaixo do prompt, depois de uma linha com o texto
"## DADOS". Desligue a busca na web e a memória entre conversas, ou use conversa temporária, se a
ferramenta oferecer essas opções. Este prompt serve de linha de base, e a saída dele será
comparada com a do prompt estruturado.

```
Analise essa proposta de projeto e me diga se ela está boa para ir ao conselho.
```

Copie a resposta inteira, sem editar, para o documento-do-participante.docx.
