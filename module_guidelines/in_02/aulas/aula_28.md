# Aula 28 - TESTES COM USUÁRIOS

## Descrição da Aula
O teste de dados é uma técnica que envolve a realização de testes com um grupo de usuários que representa a população alvo do site ou aplicativo. O objetivo é obter informações sobre como os usuários interagem com o produto, quais são suas necessidades e expectativas, e onde estão os principais pontos de frustração ou dificuldade.
