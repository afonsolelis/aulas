## Contexto e Objetivo

O Capítulo 2 apresenta os fundamentos da modelagem de negócios como etapa preliminar à modelagem de software. Você aprenderá a identificar atores, casos de uso organizacionais, regras de negócio e o vocabulário do domínio — elementos essenciais para construir a visão Enterprise do RM-ODP. Este conteúdo dá base para o artefato da Sprint 1 (mapa de atores + RF/RNF).

**Eixo disciplinar:** Computação
**Assuntos:** Arquitetura da Web
,Engenharia de requisitos
**Duração recomendada:** 0 min
