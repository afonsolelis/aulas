## Contexto e Objetivo

As Diretrizes de Acessibilidade para o Conteúdo da Web (WCAG) são parte de uma série de recomendações para acessibilidade para a web publicadas pela Web Accessibility Initiative do W3C. No entanto, trata-se de uma documentação bastante técnica, e é comum que diversos autores introduzam este conteúdo de forma mais amigável e acessível. Neste material você conhecerá o trabalho de Marcelo Sales, que criou um kit de ferramentas para facilitar o trabalho com o WCAG. Além de assistir o vídeo, você pode consultar o material em https://guia-wcag.com/

**Eixo disciplinar:** User Experience

## Conceitos-Chave

Os assuntos centrais deste autoestudo são:

- **O conceito de inclusão e pessoa com deficiência**
- **Usabilidade**

Cada conceito deve ser compreendido a ponto de o aluno conseguir explicá-lo com as próprias palavras e aplicá-lo ao projeto em andamento.

## Aplicação no Projeto

Relacione o conteúdo deste autoestudo ao projeto do squad:

- Como este conceito se manifesta no domínio do parceiro?
- Quais decisões de arquitetura ou modelagem ele influencia?
- Que artefato (RF, RN, RNF, diagrama, teste) ele sustenta?
