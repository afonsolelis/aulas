## Contexto e Objetivo

Este é um dos assuntos mais importantes quando queremos fazer a integração entre o front-end e o back-end de uma aplicação web. O fetch() envolve uma requisição de dados do cliente para o servidor, e envolve uma série de conceitos de redes e chamadas assíncronas que você deve compreender para fazer com que seu sistema lide da melhor forma possível com requisições ao servidor e suas respostas, sejam elas realizadas com sucesso ou fracasso. Este material introduz a prática com fetch(), mas você deve realizar os demais autoestudos para compreender tudo o que existe por trás dessas requisições importantes no mundo do desenvolvimento web.

**Eixo disciplinar:** Computação
**Assuntos:** JavaScript XMLHttpRequest e API Web
,Camada de aplicação
,Arquitetura da Web
,Algoritmos de busca e ordenação
