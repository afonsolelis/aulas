## Contexto e Objetivo

User Stories, no contexto do Scrum, muitas vezes não surgem a partir de Personas, e isso pode implicar no mapeamento de funcionalidades e recursos que não correspondem às reais necessidades das pessoas. Precisamos evitar esse tipo de construção! Com este material, você poderá refletir sobre como as pessoas, para as quais criaremos nossa solução, estarão presentes a cada User Story escolhida, a cada Task movida de "fazendo" para "feito". É preciso não esquecer das pessoas no processo!

**Eixo disciplinar:** User Experience
**Assuntos:** Personas
**Duração recomendada:** 0 min

## Conceitos-Chave

Os assuntos centrais deste autoestudo são:

- **Personas**

Cada conceito deve ser compreendido a ponto de o aluno conseguir explicá-lo com as próprias palavras e aplicá-lo ao projeto em andamento.

## Aplicação no Projeto

Relacione o conteúdo deste autoestudo ao projeto do squad:

- Como este conceito se manifesta no domínio do parceiro?
- Quais decisões de arquitetura ou modelagem ele influencia?
- Que artefato (RF, RN, RNF, diagrama, teste) ele sustenta?
