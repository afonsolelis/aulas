## Contexto e Objetivo

Este capítulo apresenta as melhores práticas de tratamento de erros segundo Robert C. Martin, incluindo: usar exceções em vez de códigos de erro, escrever blocos try-catch-finally primeiro, usar exceções não verificadas para erros de programação, fornecer mensagens de erro descritivas e definir classes de exceção específicas para o domínio. Este conteúdo é essencial para a aula, pois ensina a implementar tratamento de erros robusto nos endpoints, garantindo que erros de negócio e validação sejam comunicados claramente ao cliente via status codes HTTP apropriados (400, 404, 409, 422).

**Assuntos:** Abordagens de testes de software
