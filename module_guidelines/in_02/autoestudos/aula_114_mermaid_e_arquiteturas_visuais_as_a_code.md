## Contexto e Objetivo

O Mermaid é uma ferramenta poderosa e versátil para criar diagramas e gráficos a partir de texto inspirado no Markdown. Neste guia de autoestudo, você aprenderá a utilizar o Mermaid para criar diferentes tipos de diagramas, desde fluxogramas até gráficos de Gantt.

**Eixo disciplinar:** Computação
**Assuntos:** Arquitetura da Web
**Duração recomendada:** 0 min
