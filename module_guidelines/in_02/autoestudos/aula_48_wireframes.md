## Contexto e Objetivo

Nesta etapa de planejamento, queremos validar o mais rápido possível nossas ideias com os parceiros de negócios, não é mesmo? Uma das formas mais rápidas de expressarmos ideias de solução é utilizando wireframes. Mas não basta apenas desenhar, é preciso considerar Personas e contextos de uso, além das User Stories, pra que esse desenho faça sentido para quem analisar. Neste material você irá aprender o que é wireframe, qual o seu papel estratégico, e o que é necessário para fazer um de forma organizada.

**Eixo disciplinar:** User Experience
**Assuntos:** User Experience
,Design thinking
,Design de interação
