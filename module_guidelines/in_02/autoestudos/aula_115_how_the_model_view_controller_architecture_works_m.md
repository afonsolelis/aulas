## Contexto e Objetivo

A arquitetura MVC (Model-View-Controller) é amplamente utilizada no desenvolvimento de aplicações web, mas muitas vezes é complementada por uma camada de serviços (Service Layer) para melhorar a organização e reutilização de lógica de negócios. Neste artigo, exploraremos como a arquitetura MVC pode ser estendida com uma camada de serviços.

**Eixo disciplinar:** Computação
**Assuntos:** Padrões arquiteturais MVC, MVP e MVVM
