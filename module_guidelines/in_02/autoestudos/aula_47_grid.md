## Contexto e Objetivo

Grids são orientações importantes para uma boa organização das estruturas visuais de uma interface de usuário. Você pode utilizá-los para começar bem o seu wireframe e evitar retrabalhos lá na frente. Neste material você vai conhecer diferentes sistemas de grid e um pouco da história dessa importante ferramenta.

**Eixo disciplinar:** User Experience
**Assuntos:** User Experience
,Usabilidade
,Design de interação
**Duração recomendada:** 0 min
