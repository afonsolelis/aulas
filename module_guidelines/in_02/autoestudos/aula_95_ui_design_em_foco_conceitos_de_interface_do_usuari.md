## Contexto e Objetivo

Este autoestudo aborda os principais conceitos e princípios de Interface do Usuário (UI), destacando estratégias para criar interfaces intuitivas, funcionais e eficazes. O objetivo é capacitar o estudante a solucionar problemas de usabilidade e interação, garantindo uma experiência agradável e produtiva aos usuários.

**Eixo disciplinar:** User Experience
**Assuntos:** Design de interação
**Duração recomendada:** 0 min

---

## Conceitos-Chave

Os assuntos centrais deste autoestudo são:

- **Design de interação**

Cada conceito deve ser compreendido a ponto de o aluno conseguir explicá-lo com as próprias palavras e aplicá-lo ao projeto em andamento.

## Aplicação no Projeto
