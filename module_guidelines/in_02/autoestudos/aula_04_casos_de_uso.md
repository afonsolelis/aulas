## Contexto e Objetivo

Leia o capítulo 9 do livro "UML Essencial - Um breve guia para a linguagem-padrão de modelagem de objetos"
Os casos de uso são uma técnica para captar os requisitos funcionais de um sistema. Eles servem para descrever as interações típicas entre os usuários de um sistema e o próprio sistema, fornecendo uma narrativa sobre como o sistema é utilizado.

**Eixo disciplinar:** Computação
**Assuntos:** Engenharia de requisitos
,Elicitação de requisitos
**Duração recomendada:** 0 min

Os assuntos centrais deste autoestudo são:

- **Engenharia de requisitos**
- **Elicitação de requisitos**
