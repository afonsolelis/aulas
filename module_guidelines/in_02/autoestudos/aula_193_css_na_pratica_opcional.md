## Contexto e Objetivo

"Neste vídeo você vai conhecer propriedades modernas do CSS e entender quais as possibilidades de criação que elas possuem. Uma delas é o seletor :has() , que funciona quase como um if na programação.
Além de outras propriedades de box model, flex, e, também, o input rádio do HTML. E para que tudo isso funcione em navegadores antigos, você vai aprender a adicionar um pequeno código em JavaScript com DOM."

**Eixo disciplinar:** Computação
**Assuntos:** Aplicação de layout HTML + CSS
