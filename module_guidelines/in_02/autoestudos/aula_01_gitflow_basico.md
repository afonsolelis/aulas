## Contexto e Objetivo

Pois bem... no módulo 1, seu grupo ficava só fazendo commit e push do jogo na main branch do repositório do Github? Parem já com essa patifaria! Gitflow é o que vocês precisam aprender para organizar como cada membro do grupo pode fazer suas contribuições no Github de uma forma bem estruturada, sem prejudicar a versão que já funciona do seu software. Gitflow é uma prática de mercado bastante importante, e por isso vocês precisam aprender bem! Leia este autoestudo, mas fique tranquila(o): ao longo do módulo vocês terão bastante espaço para praticar, acertar e errar, até ganharem a experiência necessária!

**Eixo disciplinar:** Computação
**Assuntos:** Servidores de página e de aplicação
**Duração recomendada:** 0 min
