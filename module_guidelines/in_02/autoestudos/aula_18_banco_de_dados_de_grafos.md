## Contexto e Objetivo

Para quem for para a Ciência da Computação, o módulo 5 trabalhará com bancos de dados de grafos! Mas isso não quer dizer que em outros cursos isso não é importante, ok? Neste material você conhecerá bancos de dados modelados conforme essa super estrutura de dados chamada grafo, que inclusive você conhecerá mais através dos professores de Matemática. Aqui temos uma introdução ao assunto, para você se familiarizar com estas noções.
