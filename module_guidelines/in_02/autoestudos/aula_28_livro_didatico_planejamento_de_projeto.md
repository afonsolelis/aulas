## Contexto e Objetivo

O Capítulo 4 apresenta técnicas de planejamento de projeto de software baseadas em casos de uso, incluindo a identificação de atores, a definição de casos de uso e o relacionamento entre eles. Este conteúdo é essencial para a Aula 2, pois auxilia na delimitação do escopo do sistema e na identificação das entidades principais que compõem o minimundo. Você aprenderá a usar casos de uso como base para o planejamento e a estimativa de esforço, conectando requisitos à modelagem de dados.

**Eixo disciplinar:** Computação
**Assuntos:** Banco de dados relacional
**Duração recomendada:** 0 min
