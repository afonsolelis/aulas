## Contexto e Objetivo

CSS é um universo particular de códigos e técnicas para criar estilo e mesmo comportamento (animações, responsividade) a elementos de HTML. Nesta primeira parte do conteúdo de CSS da MDN, você aprenderá os conceitos fundamentais do CSS. É bem curtinho, e você já pode seguir para a parte 2 só clicando no link deste próprio conteúdo.

**Eixo disciplinar:** Computação
**Assuntos:** Aplicação de layout HTML + CSS
,Criação e formatação de páginas web com CSS
**Duração recomendada:** 0 min
