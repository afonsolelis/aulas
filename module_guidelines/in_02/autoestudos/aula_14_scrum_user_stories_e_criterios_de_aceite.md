## Contexto e Objetivo

User Stories são a "espinha dorsal" de um projeto de tecnologia sob o Scrum. Elas conectam os interesses não apenas de um cliente, mas principalmente os interesses, dores e necessidades das pessoas que se beneficiarão da solução, garantindo que se crie valor para quem realmente irá utilizá-la. Mapear User Stories não é tarefa simples, mas há método para isso, e esse material busca esclarecer as melhores práticas para a construção dessas histórias que irão compor o Product Backlog do seu projeto.
