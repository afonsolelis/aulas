# Aula 12 - PREVISÃO DE DEMANDA (MODELOS MATEMÁTICOS)

## Descrição da Aula
O encontro visa capacitar o aluno a diagnosticar a estrutura de uma série de demanda e a escolher e aplicar o método de previsão correspondente.  Toda série é tratada como soma de quatro camadas (nível, tendência, sazonalidade e ruído) e cada método é apresentado como uma estrutura que guarda algumas dessas camadas e descarta as outras: média móvel, média móvel ponderada e suavização exponencial simples para séries sem tendência; suavização exponencial dupla para séries com tendência; índice sazonal para séries com padrão de calendário.
