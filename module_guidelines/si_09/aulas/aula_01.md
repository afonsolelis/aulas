# Aula 1 - ESBOÇO E TÉCNICAS AVANÇADAS DE WIREFRAMING E VISUALIZAÇÃO DE DADOS

## Descrição da Aula
Nesta aula, vamos explorar técnicas avançadas de esboço e wireframing, essenciais para qualquer designer eficaz. Além disso, com a crescente importância dos dados em design, focaremos também em métodos impactantes de visualização de dados e daremos uma introdução à arte de visualização de dados.
