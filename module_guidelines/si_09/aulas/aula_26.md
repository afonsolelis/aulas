# Aula 26 - REFATORANDO CÓDIGOS

## Descrição da Aula
Objetivo da Aula: Aprender técnicas de refatoração de código para melhorar a legibilidade, manutenção e desempenho dos projetos de software.
Introdução à Refatoração de Códigos: Apresentação dos conceitos fundamentais de refatoração. Explicação sobre a importância de refatorar o código regularmente para manter a qualidade e a sustentabilidade do software ao longo do tempo.
Identificação de Código Smells:
Explicação sobre o que são "code smells" (indicadores de problemas no código) e como identificá-los.
Exemplos práticos de code smells comuns, como métodos longos, duplicação de código,…
