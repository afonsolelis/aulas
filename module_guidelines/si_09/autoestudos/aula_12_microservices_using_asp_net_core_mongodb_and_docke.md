## Contexto e Objetivo

Este autoestudo em sala de aula ponderado pede a aplicação de um banco de dados mongoDB em microserviços na plataforma .net orquestrado por um docker-compose

**Eixo disciplinar:** Computação
**Assuntos:** Padrões arquiteturais MVC, MVP e MVVM
,Projeto e arquitetura de sistemas
**Duração recomendada:** 0 min
