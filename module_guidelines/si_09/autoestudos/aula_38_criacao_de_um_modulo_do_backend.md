## Contexto e Objetivo

Descrição: Nesta atividade, você deve criar um componente de backend utilizando os padrões MVC (Model-View-Controller) para uma aplicação em C#. Você pode escolher entre criar um Repository, um Model, um Service ou um Helper. O objetivo é aplicar as boas práticas de desenvolvimento e garantir que o código seja modular, reutilizável e facilmente manutenível.

Etapas da Atividade:

- Escolha do Componente: Selecione qual componente você irá desenvolver (Repository, Model, Service ou Helper).
- Implementação do Componente: Desenvolva o componente escolhido seguindo os padrões de projeto e boas práticas de desenvolvimento.
- Integração com o Backend: Integre o componente desenvolvido ao backend da aplicação, garantindo que ele funcione corretamente e atenda aos requisitos estabelecidos.
