## Contexto e Objetivo

Um exemplo de um Jupyter Notebook em Python demonstrando como realizar uma previsão de demanda usando o modelo ARIMA (AutoRegressive Integrated Moving Average). O exemplo utiliza dados sintéticos para ilustrar o processo, mas o mesmo código pode ser facilmente adaptado para dados reais.
Observação: Para executar esse notebook, você precisará das bibliotecas:
pandas
numpy
matplotlib
statsmodels (em particular statsmodels.tsa.arima.model)

**Eixo disciplinar:** Matemática e Física
**Assuntos:** Modelagem conceitual e lógica de dados
**Duração recomendada:** 0 min
