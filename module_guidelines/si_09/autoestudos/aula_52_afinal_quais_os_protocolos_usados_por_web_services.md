## Contexto e Objetivo

Este tópico de fórum discute os três estilos de comunicação que podem ser usados por serviços web: SOAP, REST e XML-RPC. Ele fornece uma breve visão geral de cada protocolo e explica como eles funcionam.

**Eixo disciplinar:** Computação
**Assuntos:** JavaScript XMLHttpRequest e API Web
**Duração recomendada:** 0 min
