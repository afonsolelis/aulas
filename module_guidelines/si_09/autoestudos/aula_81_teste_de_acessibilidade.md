## Contexto e Objetivo

Os testes de acessibilidade são essenciais para assegurar que aplicações, sejam elas web ou móveis, sejam projetadas para atender a todos os usuários, incluindo aqueles com deficiências. Esses testes podem ser conduzidos de diversas maneiras: manualmente, por especialistas, por meio de ferramentas automatizadas ou com o feedback direto das pessoas que têm deficiências. Ao envolver diretamente os usuários com deficiências no processo, obtemos insights fundamentais para aprimorar a acessibilidade e usabilidade das aplicações.

**Eixo disciplinar:** User Experience
**Assuntos:** Técnicas de visualização da informação
,Interfaces de comunicação
,Design de interação
,Usabilidade
,Diversidade, inclusão e acessibilidade
