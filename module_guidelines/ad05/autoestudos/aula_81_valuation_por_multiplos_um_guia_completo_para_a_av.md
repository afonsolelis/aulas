## Contexto e Objetivo

O processo de valuation tem um papel fundamental no mundo das finanças corporativas, sendo uma das principais ferramentas utilizadas para determinar o valor de uma empresa. A avaliação precisa de uma companhia é essencial não apenas para as aquisições, mas também para a tomada de decisões estratégicas, como investimentos e fusões.  O objetivo deste artigo é proporcionar uma visão geral sobre a avaliação por múltiplos.
