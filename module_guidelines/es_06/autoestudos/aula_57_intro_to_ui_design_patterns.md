## Contexto e Objetivo

Um padrão de design é uma solução reutilizável para um problema que ocorre comumente. Assim como uma receita culinária fornece os ingredientes e a estrutura que compõem um prato reconhecível, um padrão de design também fornece uma solução identificável e previsível para um problema de design de interface.

**Eixo disciplinar:** User Experience
**Assuntos:** Avaliação de IHC
,User Experience
,Usabilidade
,Prototipação
,Paradigmas e componentes de IHC
,Design de interação
**Duração recomendada:** 0 min
