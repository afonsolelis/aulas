## Contexto e Objetivo

Este guia detalha o uso de triggers no PostgreSQL, explicando como criar, modificar e excluir triggers. Ele cobre os diferentes tipos de triggers e fornece exemplos de casos de uso, como auditoria de alterações e manutenção de integridade referencial. O material é prático e adequado para quem deseja implementar automações no banco de dados.

**Eixo disciplinar:** Computação
**Assuntos:** Banco de dados relacional
,SQL Avançado
