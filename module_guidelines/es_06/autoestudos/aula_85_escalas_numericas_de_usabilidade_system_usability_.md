## Contexto e Objetivo

Usabilidade é algo difícil de medir — especialmente de forma quantitativa. Testes com usuários reais ajudam a identificar rapidamente quais tarefas geram mais dificuldade no uso do seu produto. Uma das formas amplamente utilizadas para quantificar a usabilidade é o System Usability Scale (SUS) — um método prático e reconhecido para avaliar o nível de usabilidade de um sistema a partir da percepção dos próprios usuários.
