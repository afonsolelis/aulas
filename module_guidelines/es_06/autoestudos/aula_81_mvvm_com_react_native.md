## Contexto e Objetivo

No vídeo de hoje, o educador e mentor na Catapulta, Ismael Moreira trás o tema: Model-view-viewmodel que seria um padrão de arquitetura de software que facilita a separação do desenvolvimento da interface gráfica do usuário.

**Eixo disciplinar:** Computação
**Assuntos:** Programação orientada a objetos
,Servidores de página e de aplicação
,Camada de aplicação
,Padrões arquiteturais MVC, MVP e MVVM
,Navegadores
,Integração avançada com JQuery + JSON + Ajax
,Criação e formatação de páginas web com HTML
,Arquitetura da Web
,Aplicação de layout HTML + CSS
**Duração recomendada:** 0 min

## Conceitos-Chave

Os assuntos centrais deste autoestudo são:

- **Programação orientada a objetos**
- **Servidores de página e de aplicação**
- **Camada de aplicação**
- **Padrões arquiteturais MVC**

- **Integração avançada com JQuery + JSON + Ajax**

Cada conceito deve ser compreendido a ponto de o aluno conseguir explicá-lo com as próprias palavras e aplicá-lo ao projeto em andamento.
