## Contexto e Objetivo

O link Chapter 43. PL/pgSQL — SQL Procedural Language [https://www.postgresql.org/docs/15/plpgsql.html] direciona para o capítulo da documentação oficial do PostgreSQL 15 dedicado à linguagem PL/pgSQL, utilizada para programar stored procedures e functions diretamente no banco de dados. Trata-se de uma linguagem procedural incorporada ao PostgreSQL que permite criar blocos de código estruturado com variáveis locais, comandos condicionais, laços de repetição, cursores e tratamento de exceções, oferecendo recursos semelhantes a linguagens como PL/SQL (Oracle) ou T-SQL (SQL Server). O conteúdo explica como declarar e implementar funções e procedimentos armazenados, destacando a diferença entre ambos.
