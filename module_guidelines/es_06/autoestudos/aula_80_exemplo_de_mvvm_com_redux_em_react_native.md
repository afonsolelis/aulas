## Contexto e Objetivo

Neste exemplo, vamos criar uma aplicação simples de contador usando o padrão MVVM com Redux em React Native. Vamos criar um contador que permite aumentar e diminuir o valor exibido na tela.

**Eixo disciplinar:** Computação
**Assuntos:** Criação e formatação de páginas web com HTML
,Aplicação de layout HTML + CSS
,Arquitetura da Web
,Camada de aplicação
,Criação e formatação de páginas web com CSS
,Integração avançada com JQuery + JSON + Ajax
,Navegadores
,Padrões arquiteturais MVC, MVP e MVVM
,Servidores de página e de aplicação
**Duração recomendada:** 0 min
