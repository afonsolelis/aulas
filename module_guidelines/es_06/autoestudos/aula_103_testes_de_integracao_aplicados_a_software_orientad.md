## Contexto e Objetivo

Este artigo acadêmico apresenta heurísticas para ordenar classes durante testes de integração em software orientado a objetos, visando reduzir o esforço necessário. Utiliza diagramas de classes UML para estabelecer uma sequência de integração, antecipando decisões no planejamento dos testes. Inclui um estudo de caso comparando os resultados com abordagens existentes na literatura.

**Eixo disciplinar:** Computação
**Assuntos:** Testes unitários
,Planejamento de testes
,Análise de sistemas de software
,Comunicação e sincronização de processos
**Duração recomendada:** 0 min
