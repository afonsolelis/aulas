## Contexto e Objetivo

A partir da versão 0.73, o React Native deprecia a integração nativa com o Flipper, ferramenta de depuração utilizada até então. Isso significa que novos projetos criados com o React Native não incluirão mais o Flipper por padrão, e os desenvolvedores que desejarem utilizá-lo precisarão integrá-lo manualmente em seus projetos (ver mais em Flipper - All you need to know: https://www.youtube.com/watch?v=D2zjvKPNltU) [https://www.youtube.com/watch?v=D2zjvKPNltU)]
Para substituir o Flipper, a equipe do React Native está trabalhando em um novo depurador JavaScript experimental, que oferece uma interface baseada no Chrome DevTools, otimizada para o motor Hermes.
