## Contexto e Objetivo

Este tutorial oferece uma introdução prática às transações no PostgreSQL, explicando como utilizar os comandos associados. Ele também aborda os conceitos fundamentais das propriedades ACID (Atomicidade, Consistência, Isolamento e Durabilidade) e fornece exemplos práticos de como aplicar transações para garantir a integridade dos dados.

**Eixo disciplinar:** Computação
**Assuntos:** SQL Avançado
,Banco de dados relacional
