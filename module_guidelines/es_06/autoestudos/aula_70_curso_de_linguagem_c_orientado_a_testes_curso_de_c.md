## Contexto e Objetivo

O curso de linguagem C orientado a testes ensina a desenvolver software em C aplicando a metodologia Test Driven Development (TDD). Os alunos aprenderão a criar testes antes de implementar a lógica do código, garantindo maior qualidade, modularidade e facilidade de manutenção. O curso aborda desde conceitos básicos da linguagem C até a aplicação de TDD em projetos reais, com foco na criação de testes automatizados e práticas de refatoração.

**Eixo disciplinar:** Computação
**Assuntos:** Modelos de arquitetura de sistemas distribuídos
,Serviços Web
,Arquitetura da Web
**Duração recomendada:** 0 min
