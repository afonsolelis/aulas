## Contexto e Objetivo

Neste artigo daremos o primeiro passo com o React Native preparando um ambiente de desenvolvimento com os recursos necessários para criar aplicativos com esse framework.

**Eixo disciplinar:** Computação
**Assuntos:** Aplicação de layout HTML + CSS
,Arquitetura da Web
,Camada de aplicação
,Criação e formatação de páginas web com CSS
,Criação e formatação de páginas web com HTML
,Integração avançada com JQuery + JSON + Ajax
,Navegadores
,Padrões arquiteturais MVC, MVP e MVVM
,Programação orientada a objetos
**Duração recomendada:** 0 min

## Conceitos-Chave

Os assuntos centrais deste autoestudo são:

- **Aplicação de layout HTML + CSS**
- **Arquitetura da Web**
- **Camada de aplicação**
- **Criação e formatação de páginas web com CSS**
- **Criação e formatação de páginas web com HTML**
