# Aula 26 - DATAAPP TECHNICAL INFOGRAPHICS

## Descrição da Aula
The objectives of this lesson are for students to understand the fundamental principles of Data Visualization, to learn how to build effective visualizations to communicate complex data, to apply data visualization techniques to enrich data presentation in the DataApp, and to use specific tools to create interactive and appealing visualizations with Streamlit.
