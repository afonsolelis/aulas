# Aula 22 - STATISTICAL INFERENCE: HYPOTHESIS TESTING

## Descrição da Aula
Statistical Inference: Hypothesis Testing. This session will cover hypothesis testing, which aims to provide a methodology that allows us to verify whether sample data provide evidence that supports a formulated (statistical) hypothesis.
