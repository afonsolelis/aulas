# Aula 2 - ARCHITECTURAL TACTICS FOR DATA FLOW AND TRANSFORMATIONS

## Descrição da Aula
The objectives of this class are for students to understand the concept and application of Component UML, to learn the medallion architecture for data engineering and pipelines, to design an architecture using Component UML, and to grasp the principles of a scalable Big Data architecture. By the end of the session, students should be able to connect these concepts and apply them to real-world data challenges.
