### DataAPP - First Version

**Peso:** 4 | **Semana:** 8

**Objetivo:**

In this artifact, students must develop the first functional version of the DataAPP. The application must retrieve information directly from the Data Cube created in the previous sprint and support interactive filters that automatically update the displayed information. The DataAPP must also integrate a fully automated pipeline responsible for updating the Data Cube from the raw ingestion table. The objective is to deliver an interactive analytical experience supported by a reliable and continuously updated data flow.
The DataAPP must include: filter-driven data updates, automated retrieval of data from the Data Cube views, and complete documentation describing the system architecture, data flow, update mechanism, and technical decisions.
