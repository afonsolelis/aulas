## Artefatos da Sprint

### Data Ingestion Structure

**Peso:** 5 | **Semana:** 4

**Objetivo:**

In this artifact (Data_Ingestion.md) , students must develop an ETL (Extract, Transform, Load) process to integrate data into an OLAP database (Data Warehouse) from an Object Storage. The goal is to create a robust structure that allows efficient data ingestion, ensuring data is properly prepared for advanced analysis. Additionally, students will model the system architecture using UML, representing the full structure from data collection to the DataAPP.
Follow all the guidelines in Sprint Increment Delivery Checklist.

**Barema:**

Assessment Criteria:
 * Efficient and appropriate data extraction
 * Proper transformations ensuring data quality
 * Correct loading into the OLAP database
 * Clear component UML diagram representing the architecture and interactions
 * Detailed documentation explaining the process
