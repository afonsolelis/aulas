### Data Discovery with Data Model Canvas

**Peso:** 3 | **Semana:** 2

**Objetivo:**

The Data Model Canvas (DMC) is a visual tool designed to structure and organize information about data-driven products and services.
This assignment requires students to produce a complete Data Model Canvas, supported by a data analysis implemented in Jupyter Notebook with Apache Spark, focusing on discovering opportunities and generating innovative insights based on the partner’s context.
The final deliverable should combine conceptual modeling (via the DMC) and practical data analysis, demonstrating the team’s ability to leverage data to solve real problems creatively and effectively.
The deliverables must be stored in the repository under /docs/data_model_canvas/.
