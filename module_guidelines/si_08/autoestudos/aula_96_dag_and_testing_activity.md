## Contexto e Objetivo

This is an individual activity. Each student must create a unique branch and implement both unit tests and a Prefect pipeline. The solution must be documented in a Pull Request, which should include a detailed description of the implementation, testing approach, and any relevant usage instructions. Collaboration or code sharing is not allowed. Only the branch link should be submitted as the answer.
The final deadline for submission is Friday of the graded activity week.

**Eixo disciplinar:** Computação
**Assuntos:** Árvores, caminhos e ciclos
**Duração recomendada:** 0 min
