## Contexto e Objetivo

Students are required to design a data architecture proposal that covers the entire data lifecycle, including data ingestion, data processing (treatment), and data visualization. The architecture should clearly illustrate how data flows from sources through transformation stages to final presentation layers, emphasizing scalability, efficiency, and clarity.
The final deadline for submission of the graded activity is 16:00 hours.

**Eixo disciplinar:** Computação
**Assuntos:** Arquitetura de banco de dados on premisse
