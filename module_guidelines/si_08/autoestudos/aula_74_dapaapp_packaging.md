## Contexto e Objetivo

In this individual activity, students are required to package their data application code as a Python package. The task includes organizing the project structure according to packaging best practices, creating necessary files such as setup.py or pyproject.toml, writing tests to validate functionality, and ensuring the package can be installed and reused. The delivery must follow the branch naming and submission rules as specified.
The deadline is this friday.

**Eixo disciplinar:** Computação
**Assuntos:** Qualidade de Software
**Duração recomendada:** 0 min
