## Contexto e Objetivo

In this individual activity, students will complete a specific programming challenge trail on the BeeCrowd platform. The set of problems is curated to progressively develop algorithmic and coding skills. Students must submit solutions that correctly solve each problem, demonstrating understanding and application of programming concepts. The activity encourages practicing problem-solving, coding efficiency, and logical thinking in a competitive programming context.

Access bcwd.me/d-15205 and use the code ftrKV-6 to be able to access the list of challenges you need to solve.

**Eixo disciplinar:** Computação
**Assuntos:** Lógica algorítmica
,Dados, informação e conhecimento
