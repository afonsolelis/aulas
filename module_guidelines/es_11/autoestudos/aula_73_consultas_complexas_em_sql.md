## Contexto e Objetivo

Capítulo de consultas avançadas em SQL para as procedures que devem estar no pacote de dados via Python ou R. Este capítulo serve de base para relembrar as queries complexas em bancos de dados relacionais e BigData.

**Eixo disciplinar:** Computação
**Assuntos:** Dados, informação e conhecimento
,Modelo de entidades e relacionamentos (MER)
**Duração recomendada:** 0 min
