## Contexto e Objetivo

Capítulo de livro que explica, de forma acessível, os princípios de codificação visual (posição, comprimento, cor, área) usados para comparar dados de forma clara e sem distorção.

**Eixo disciplinar:** User Experience
**Assuntos:** Usabilidade
,Dashboards
**Duração recomendada:** 0 min

## Conceitos-Chave

Os assuntos centrais deste autoestudo são:

- **Usabilidade**
- **Dashboards**

Cada conceito deve ser compreendido a ponto de o aluno conseguir explicá-lo com as próprias palavras e aplicá-lo ao projeto em andamento.
