## Contexto e Objetivo

O artigo oficial do ClickHouse detalha passo a passo como conectar o Power BI (incluindo Desktop e Service) ao ClickHouse, explicando pré-requisitos, instalação do driver ODBC, uso do conector nativo e configuração de gateways para trabalho em nuvem. O tutorial cobre:
Instalação do driver ODBC ClickHouse.
Uso do conector dedicado dentro do Power BI Desktop (disponível a partir da versão 2.137.751.0).
Configuração da conexão: hostname, usuário, senha, base de dados.
Visualização e importação dos dados para o Power BI.
Publicação dos dashboards e configuração do gateway para uso na nuvem.

**Eixo disciplinar:** Computação
**Assuntos:** Dashboards
,Dados, informação e conhecimento
