## Contexto e Objetivo

Pontos abordados no autoestudo:
 * Definição de dados pessoais e dados sensíveis;
 * Bases legais para tratamento;
 * Tratamento de dados sensíveis;
 * Dados de crianças e adolescentes;
 * Direitos dos titulares;
 * Atores envolvidos (controlador, operador, DPO);
 * Transferência internacional de dados;
 * Registro de atividades de tratamento;
 * Avaliação de impacto (DPIA);
 * Comunicação de incidentes (data breach);
 * Penalidades.

**Eixo disciplinar:** Computação
**Assuntos:** Gerenciamento de segurança
**Duração recomendada:** 0 min
