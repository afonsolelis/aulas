## Contexto e Objetivo

OKR é a sigla para "Objective Key Results", uma metodologia para orientar os esforços das empresas em direção a objetivos cruciais mensuráveis. O modelo de gestão por OKRs busca estabelecer direções claras para alcançar os números que indicam o crescimento de um negócio.

**Eixo disciplinar:** Negócios
**Assuntos:** Frameworks para implementação da estratégia (BSC, OKR, etc.)
**Duração recomendada:** 0 min
